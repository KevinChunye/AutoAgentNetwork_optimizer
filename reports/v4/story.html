How the question changed

From pruning agent networks to buying width, depth or verification

The project started as AMC-style pruning: learn how much of each stage of a multi-agent network to keep. The pilot showed that a single senior call matched the whole network, so the question moved to evidence per dollar, and then to how a fixed budget should be split between more calls, more reasoning and checking answers.

    Process

    How the evidence was kept honest

    Preregistration

    Every paid run carried a question, prediction, kill rule and decision, checked by code before it could spend. Confirmatory tests sit in a Holm family; tests under power were demoted to exploratory before any call.

    Sealed items, blind collection

    Items were sealed by hash before any call; runs wrote no grades, and reads regraded with frozen code. A run stops itself on its own expectations: runs stopped that way, failed on a server error.

    Single reads

    Each confirmatory block was read once with code frozen before the read; no rows were added after a read was seen.

    Audits

    An independent auditor returned verdicts: GO, ADJUST, STOP. ADJUST items were fixed before any further spend.
